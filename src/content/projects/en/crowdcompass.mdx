## Problem

In a stadium it is hard to find your gate and your seat. CrowdCompass turns the ticket into a guide: you scan its QR code, the venue loads in 3D and a first-person route takes you to your seat, with points of interest and an assistant along the way.

## What I did

A five-person team project in the 4th year of Multimedia Engineering. The 3D engine, the API and the Dialogflow agent were built by my teammates. My part:

- **Landing page and user area:** design of the landing page and its tutorial, login, profile and «My events» with each user's tickets.
- **Chatbot:** the interface and its connection to Dialogflow, from the frontend to the backend.
- **Server on OVH:** Apache, HTTPS, security and the deployment of each release.

## Technical decisions

- **A chatbot with context.** Every query carries the current page and the scanned tickets, so the assistant answers based on where the user is: «show me my QR» only works inside an event.
- **A server closed by default.** HTTPS enforced with Let's Encrypt and HSTS, and a Content Security Policy that only allows the origins the application needs.
